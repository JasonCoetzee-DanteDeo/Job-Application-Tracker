# Job-Application-Tracker

--Branching Workflow--

This project will be managed through 2 main branches, namely dev and main.
-dev: This is where all new features will be developed, pushed, and reviewed
-main: This is where all features pushed to dev that are approved will be pushed to. This also acts as the production branch.

Feature branches will be created for any new development done. These branches will then be merged into dev.
